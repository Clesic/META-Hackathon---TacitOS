# Build roadmap

Scheduling update: follow the [eight-day execution plan](eight-day-plan.md) and [October 27 schedule](tomorrow-october-27.md). They supersede the day-by-day timing below, including moving the first live model test to October 27. This original roadmap is retained for context.

Planning date: October 26, 2026. Working assumption: one experienced builder with roughly 4–6 focused hours per day. This is an estimate, not a promise or a user-confirmed schedule. User-facing dates below use America/Los_Angeles.

## October 26: prepare and prove one model task

Prepared by this pack: concept, contracts, synthetic cases, hidden oracle, evaluation protocol, prompts and demo plan. Next: create a minimal model adapter and test gap diagnosis against one stalled attempt. Preserve actual requests and results locally without credentials. Stop expanding scope until the output is useful.

## October 27: deterministic rehearsal

Implement case loading, permitted actions, attempt storage and independent evaluation. Test positive, negative, missing-evidence and permission-control cases. Build a minimal task screen. No model is needed to prove the simulator's outcomes.

## October 28: gap capture

Connect the stalled attempt to a real model call. Show a focused question, collect an answer and extract a draft with supporting quotes. Reject malformed outputs and invented references. Prove that hidden fixtures never enter learner context.

## October 29: review and retrieval

Implement version-specific approval, edits, rejection and revocation. Retrieve only applicable approved guidance. Rejected or revoked cards must not leak into new answers.

## October 30: fresh transfer

Run a different case against the frozen approved snapshot. Record outcome and expert contacts. Include a boundary failure or safe request. Complete the end-to-end loop before styling additional screens.

## October 31: all three families

Extend the same implementation to duplicate orders and split deliveries. Add non-knowledge controls. Resolve model failures and make reset reliable. Optional voice only if these gates pass.

## November 1: evaluation and feature freeze

Freeze corpora, test sets and prompts. Run document-only, raw-answer and approved-guidance comparisons. Add an equal-time interview condition only if an actual expert session is available. Label automated roles. Record failures and limitations.

## November 2: first full video

Record a repeatable flow, including expert review and a negative case. Improve legibility and pacing. If the live model is unreliable, show a labelled replay of an actual captured run; do not replace it with fabricated output.

## November 3: package

Finish verified results, startup instructions, provenance and a public-ready source tree. Inspect for credentials and runtime data. Check official submission requirements. No publication is performed by this document pack.

## November 4: buffer

Target submission by 15:00 Pacific, before the published deadline of 18:00 Pacific / 21:00 Eastern. Confirm current official rules and upload requirements. Preserve a submission receipt. Avoid new features.

## Scope recovery

If time slips, cut voice, extra scenario families and visual embellishments. Preserve one genuine capture-to-retest loop, a negative case, evidence boundaries and honest results. Never replace approval or independent grading with a hard-coded happy path.

# Missing Monday

Could your team get through Monday without its most experienced employee?

This repository is the Missing Monday project for the Meta Global AI Developer Hackathon, Indie track. A successor rehearses a synthetic purchasing case, the expert types the missing condition, and a fresh case shows that approved card.

Open the project notes in [Missing Monday](Missing%20Monday/README.md).

```sh
cd "Missing Monday"
python3 -m app.server
```

Then open http://127.0.0.1:8766. Python 3.9 or later is enough. No packages and no API key are required for this rehearsal.

Alder Works and every order are fictional. The app does not call a model yet, and it does not place real orders.
